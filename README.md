## Python Installation and Virtual Environment Setup

```
sudo apt update
sudo apt install python3
sudo apt-get install python3-venv
cd ~/
mkdir arnmap
cd ~/arnmap
python3 -m venv arnmap
dir ~/arnmap
source ~/arnmap/bin/activate
pip install boto3
pip list
deactivate
```
